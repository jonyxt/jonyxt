# Python Backend Developer

Разрабатываю backend-проекты на Python. Основное направление — FastAPI, PostgreSQL, асинхронная работа с базой данных, REST API и тестирование. Рассматриваю вакансии Junior Python Backend Developer.

## Проекты

- **[Meeting Room Booking API](https://github.com/jonyxt/meeting-room-booking-api)** — REST API для бронирования переговорных на FastAPI и PostgreSQL. Асинхронный SQLAlchemy, JWT-авторизация, роли пользователей, защита от двойного бронирования, Alembic, тесты и GitHub Actions. Проект вырос из тестового задания и был переработан после его выполнения.
- **[Supplier Ordering API](https://github.com/jonyxt/supplier-ordering-api)** — учебный дипломный проект на Django REST Framework: каталог поставщиков, корзина, заказы, импорт прайс-листов и фоновые задачи на Celery с Redis.

## Технологии

- **Основной стек:** Python, FastAPI, Pydantic, PostgreSQL, SQLAlchemy (async), Alembic, asyncio.
- **Тестирование и инструменты:** pytest, pytest-asyncio, Ruff, Git, Docker, Docker Compose, GitHub Actions.
- **Дополнительные технологии:** Django, Django REST Framework, Flask, SQLite, Redis, Celery, aiohttp.

## Инфраструктура

Помимо backend-разработки занимаюсь настройкой и поддержкой собственных Linux VPS. Развёртывал веб-приложение через Docker Compose с Caddy и HTTPS, настраивал автоматические резервные копии и проверки доступности. Также поддерживаю собственную VPN-инфраструктуру на нескольких серверах и решаю связанные с ней сетевые задачи.
